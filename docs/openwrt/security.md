# 安全与验收门禁

- 不向公开仓库提交私有配置、data/private、SQLite、cookie、令牌、备份或未脱敏日志。
- 安装/升级必须校验固定版本官方 SHA256 及 Ed25519 签名；签名失败不替换程序。自编译版本另立信任链。
- 禁止无检查覆盖既有部署。先停服确认进程退出、备份数据和程序，再升级；保留回滚路径。卸载默认仅移除管理组件，保留数据和账号。
- root 管理脚本仅接受明确操作；配置文件不得由服务用户修改，不执行配置中的任意 shell；启动前检查路径、挂载、身份、cgroup 限制。
- LuCI 只开放白名单 RPC、区分读写权限、不公开凭据或通用 shell；日志脱敏。
- 资源保护门禁：实际进程 UID/GID、cgroup 归属、内存限制、OOM、空闲及播放负载；保护建立失败即不启动。不得为适配失败自动放宽限制。
- 路由器实机门禁：安装/卸载与重复操作、挂载缺失、端口冲突、服务停止/重启、冷重启及 USB 延迟挂载、音乐播放、24h 稳定性、网络及 DNS 无异常；保留原始证据于本地。
- 未完成门禁保持 Draft；不发布未经实机验证的正式安装包。
